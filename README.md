# Dr. Shin Website

## Public website

Live site: **https://sysopx786.github.io/Website-Dr-Shin/**

Repo: **https://github.com/sysopx786/Website-Dr-Shin**

If the live link is a **404**, Pages is still pointed at `main`. Logged in as **sysopx786**, open this and save once:

**[Turn on GitHub Pages](https://github.com/sysopx786/Website-Dr-Shin/settings/pages)**  
Source: **Deploy from a branch** → branch **`gh-pages`** → folder **`/ (root)`** → **Save**.

The repo is **public**. The built site is on the `gh-pages` branch.

---

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:8080](http://localhost:8080).

GitHub Pages is published from `main` via `.github/workflows/pages.yml` to the `gh-pages` branch.
